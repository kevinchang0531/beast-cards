# 靈獸卡牌對戰 Elemental Beasts TCG

原創集換式卡牌對戰遊戲（Godot 4.7，2D）。參考「收集靈獸卡、附加能量、進化、屬性相剋」這類卡牌遊戲的**類型**，
靈獸、角色、卡名、規則細節全部原創，不使用任何既有遊戲的角色或名稱。

## 怎麼玩

- **目標**：先擊倒對手 3 隻靈獸（拿到 3 顆★星徽）就獲勝；對手場上沒有靈獸、或輪到他時牌組抽光也算贏。
- **每回合**：自動抽 1 張 → 放基礎靈獸到後備（最多 4 隻）→ 進化 → 附加 1 張能量 → 用道具卡（不限）、支援卡（1 張）→ 撤退 1 次 → 攻擊（攻擊後回合結束）。
- 先攻第一回合不能攻擊；雙方第一回合、剛上場或剛進化那回合不能進化；可以從基礎到一階、再到二階，不能跳階。
- **屬性相剋**：火 → 草 → 岩 → 雷 → 水 → 火，打被剋的屬性傷害 ×2。
- **狀態**：灼傷（每回合開始受 10 傷害）、麻痺（下回合不能攻擊和撤退）；撤退或進化會解除。
- **操作**：點手牌出牌（金框＝可以出），要選目標時再點自己的靈獸；滑鼠移到卡上，右邊顯示完整卡面；右鍵取消。

## 隱藏選單

有玩家頂列的畫面，3 秒內連點左上角頭像 5 下，會開出隱藏選單：
- **補齊全部卡片**：靈獸和訓練家卡都補到 3 張（牌組上限），不動金幣和戰績。
- **改名字**：最多 8 個字，不能和現有玩家同名；存檔、戰績、進行中的對戰都跟著新名字。

## 玩家資料、牌組張數、匯入卡包

- **玩家資料**：主選單「玩家資料」可改名字、稱號、自我介紹、頭像（4 個內建或上傳自己的圖片）。
- **30／60 張**：牌組編輯右上切換，每副牌組各自設定。60 張時同名卡上限 6 張、基礎靈獸至少 8 張，電腦對手的牌組也變 60 張。
- **匯入卡包**：主選單「匯入卡包」一次選多張圖片，每張變一張卡（裁成 256×256 正方形，和內建卡圖一樣），再逐張設定種類（靈獸／訓練家／能量）、名字、屬性、HP、進化來源（基礎或一階靈獸，可做到二階）、撤退、招式；也可以按「用內建圖片做範例卡包」試用。匯入者得到每張 3 張，卡包商店也買得到。線上對戰不能帶自製卡（對手沒有卡片資料）。
- **牌組編輯看卡**：滑鼠移到卡片上放大、點了才加入；手機平板點一下加入、按住放大、拖動捲動。
- **手機平板全螢幕**：版面固定 1280×720 置中、背景鋪滿，沒有黑邊；第一次觸碰自動進全螢幕，主選單也有「全螢幕」鈕。直向時提示轉橫向。iPhone Safari 不支援全螢幕 API，要「加入主畫面」再從圖示開（主畫面版的資料和 Safari 分開）。

## 批次匯入卡片 JSON

「匯入卡包」→「批次匯入 JSON」選一個資料夾（手機改選 JSON 和圖片檔），每個 JSON 變一個卡包，圖片用 `imageUrl` 的檔名配對；轉換規則在 `scripts/card_import.gd`。遊戲不附任何匯入資料，匯入的卡只存在自己的裝置。

## 資料庫（玩家進度）

存在 `user://saves/`（Windows：`%APPDATA%\Godot\app_userdata\靈獸卡牌對戰\saves\`；網頁版存在瀏覽器裡），每位玩家一個 JSON：
名字、頭像、金幣、卡片收藏、牌組、統計（場數、勝敗、擊倒數、開包數、線上戰績）、打贏各電腦對手次數、最近 200 場對戰紀錄，
以及**進行中的電腦對戰**——每個動作後自動存檔，關掉遊戲再開，主選單會出現「繼續上一場對戰」。

對戰引擎是確定性的（同一個種子＋同樣的動作順序＝同樣結果），所以存檔只記 `{seed, decks, names, history}`，讀檔時重播即可。

## 線上對戰怎麼運作

不需要自架伺服器：用 Firebase Firestore 當「動作信箱」。
`tcg_rooms/<房號>` 存雙方名字、牌組、種子；`tcg_rooms/<房號>/actions/0000…` 依序存每個動作。
輪到誰誰就寫入下一號，對方每秒讀一次，讀到就在自己的引擎照做。權限規則在 `firebase/firestore.rules`。
設定檔 `config/online.cfg`（不進 git，範本見 `config/online.example.cfg`）；沒有設定檔時遊戲照常，只是不能線上對戰。

## 開發指令

```bash
python tools/gen_art.py           # 生圖（已有的會跳過）
python tools/process_art.py       # 原圖 → 遊戲素材
python tools/make_audio.py        # 合成音效音樂
python tools/make_font.py         # 改了中文字要重跑
godot --headless --path . --script res://tests/engine_test.gd
godot --path . res://tests/selftest.tscn
godot --headless --path . res://tests/online_test.tscn
bash tools/export_web.sh          # 網頁版 → build/web/
```
