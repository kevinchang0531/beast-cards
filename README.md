# 靈獸卡牌對戰 Elemental Beasts TCG

原創集換式卡牌對戰遊戲（Godot 4.7 網頁版）。收集 20 種原創靈獸卡、附加能量、進化、利用屬性相剋（火 → 草 → 岩 → 雷 → 水 → 火）擊倒對手 3 隻靈獸就獲勝。

**直接玩：** https://kevinchang0531.github.io/beast-cards/

- 4 位電腦對手（簡單 → 冠軍），打贏前一位解鎖下一位
- 卡包商店（贏金幣買卡包）、牌組編輯（多副牌組、自動組牌）
- 進度存在瀏覽器裡（玩家、收藏、牌組、戰績、進行中的對戰）
- 玩家資料可改名字、稱號、頭像（可上傳）；牌組可選 30 或 60 張
- 匯入卡包：用自己的圖片做卡、設定屬性
- 批次匯入：選資料夾讀卡片 JSON，屬性、招式、進化自動對應（資料只存在自己的裝置）
- 手機平板全螢幕
- 線上對戰：開房間拿 6 碼房號，朋友輸入房號加入（電腦版和網頁版可以互打）

角色、卡名、美術全部原創（美術由 AI 生成，音效音樂由程式合成）。

原始碼在 [`source/`](source/)（Godot 4.7）。線上對戰要自己建 Firebase 專案，並把 `config/online.example.cfg` 複製成 `online.cfg` 填入設定。
